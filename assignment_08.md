# Lab 8 & 9: Mini project

MSc. Mikołaj Kikolski, MSc. Damian Pawłowski

---

This assignment is a mini-project that combines skills and techniques from all previous labs. Your goal is to create a simple, but engaging game that incorporates physics, UI, and 3D scene management.

## Requirements

1. The game must consist of at least 2 scenes (for example main menu and a game scene)
2. The game must include UI elements
3. The game must include objects using physics simulations (rigid bodies, colliders, forces, etc.)
4. The game should use textured 3D models, not basic shapes unless the consistent theme of the game requires it (e.g. abstract art style, [Superhot](https://www.gry-online.pl/newsroom/superhot-vr-ofiara-review-bombingu-tworcy-usuneli-kontrowersyjna/z120276)-style approach)
5. The game should be submitted as a link to code repository alongside a built Windows executable included in the Releases section. Remember to commit with a proper `.gitignore` file!

To avoid limiting your creativity, you're eligible for additional points for surpassing these requirements.
