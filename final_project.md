The final project will require you to create a VR or AR application that will be evaluated based on the following criteria:

## Requirements (Common)

1. The game must consist of at least 2 scenes (for example main menu and a game scene)
2. The game should use 3D assets instead of basic shapes
3. The game should make use of VR/AR as an immersive environment - the game scenes should be built in 3D space and allow users to look around and possibly navigate the environment.
4. The game should be submitted as a link to code repository alongside a built Android `.apk` included in the Releases section. Remember to commit with a proper `.gitignore` file!

## Requirements (VR)

1. The game must contain world space UI elements
2. The game must use controller-based input/interaction

## Requirements (AR)

1. The game must use touch-based input/interaction
2. The game must contain UI elements
3. The game must use plane detection and anchors

Similarily to the mini project, you're eligible for additional points for surpassing these requirements. For VR, I'd like to recommend checking out [this guide on building immersion using haptic input and audio](https://learn.unity.com/tutorial/2-1-audio-and-haptics-2)
